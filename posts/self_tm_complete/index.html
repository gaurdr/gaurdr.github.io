SELF Turing Machine¶

There exists a Turing machine named SELF that can generate its own code without any external input. For details on SELF, refer to Chapter 6 (first few pages) of the Theory of Computation book by Sipser.

SELF is composed of two parts, A, B both Turing machines. First, A runs and leaves <B>, the description of TM B, on the tape. Then, B runs and analyses the contents of the tape to determine the description <A> of the Turing machine that left the contents on the tape. Finally, B combines the descriptions <A> and <B> to create a new description of SELF, denoted as <AB>.

We consider A and B as functions in the following code: We model the tape used by A,B with a global variable s.

First, we create function A(), which simply writes the description <B> into string s. We use a placeholder for now, until we write function B(). Once that’s done, we can copy and paste the code as a string (without the indentation) into s.

Next, we create the code for B(). This function needs to print function A() followed by function B(). To achieve this, we need two print statements. The first print statement prints part of function A(), and the value of s in the last line of A() is printed from s itself. The second print statement prints the code for function B(), which is in string s itself.

We will write the code in two steps. In the first step, we will print s without the surrounding single quotes, and in the second step, we will add the single quotes.

The indentation will still not be right. It would be an interesting exercise for the reader to fix the indentation. Ideally, the code that is printed should run without any reformatting.

Stage 1.¶

The complete Turing machine is located in the first cell. The tape is represented by a global variable called ’s’. Two functions, A() and B(), are used in the construction of SELF as described in the book. Note that we have to write the code for B first, then populate the hand side of s= in function A. The SELF machine can be executed by calling A and then B.

global s
# we will use s as the tape.

# A will print <B> onto s
def A():
  global s
  s = 'def B(): global s   print("def A(): global s s =", s) print(s)'


# B will use q(<B>) to print description of A
# and combine <A> with <B> to print self
def B():
  global s
  print("global s def A(): global s s =", s) # prints A()
  print(s)                                   # prints B()

Stage 2:¶

The first line prints the contents of s without quotes. As a first attempt, one could try to print ' in first print in B, but this requires escaping the quotes using \. A bit of playing around with this idea would convince you that the headache now is to print \. We need to specify the quote as a string of characters which, when printed using print, will print ' but when treated as a string is printed as a string. Single quote is also represented as chr(0x27) and this is the string we use.

A simple modification the code above: insertion of chr(0x27) before and after s is printed the first time in B does the trick. It will print s within quotes when function A is being printed. This modifies the definition of B therefore we have to update the string s in A as well.

When A,B are called one after the other then the two functions are printed as a single line. Convince yourself that the output is the same as the code in the cell (upto indentation).
